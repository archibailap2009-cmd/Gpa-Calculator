# GPA калькулятор

Простой калькулятор GPA на чистом HTML, CSS и JavaScript. Без сборки и зависимостей.

## Как запустить

Открой `index.html` в браузере.

## Как выложить на GitHub Pages

1. Создай репозиторий и загрузи в него все четыре файла.
2. Открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту сайт появится по адресу `https://<твой-ник>.github.io/<репозиторий>/`.

## Что настраивается

В `script.js`:

- `GRADES` — шкала оценок (по умолчанию 4.0 с плюсами и минусами).
- `DEFAULT_COURSES` — список предметов и кредиты.

Оценки и добавленные предметы сохраняются в браузере (localStorage).

## Формула

GPA = сумма (балл оценки × кредиты) / сумма кредитов предметов с выставленной оценкой.
